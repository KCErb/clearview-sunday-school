Use for any committed action; one primary per view, everything else secondary or quiet.

```jsx
<Button variant="primary" size="md">Begin lesson</Button>
```

Variants: `primary` (cerulean fill), `secondary` (cerulean outline), `quiet` (text only), `invert` (white fill, for photo and dark-blue grounds). Sizes `sm | md | lg`. Hover darkens, press darkens further — the brand never uses scale or lift on press.
