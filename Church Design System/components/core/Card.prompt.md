Use to group a single idea — a lesson, an announcement, a linked resource.

```jsx
<Card elevation="raised">
  <CardMedia src="/assets/images/placeholder-landscape.svg" />
  <h3>Come, Follow Me</h3>
  <p>Study the week's passages together.</p>
</Card>
```

`elevation="flat"` is the default and the most common. Reserve `floating` for genuinely overlaying content. `accent` adds a top rule in cerulean — never a coloured left border.
